Preserve corresponding source and notices when distributing or serving an AGPL-covered application; consult the actual terms before proprietary use. Dependency packages have their own licenses.

The official RoadDamageDetector README states its dataset images are CC BY-SA 4.0, while the official RDD2022 Figshare record (DOI 10.6084/m9.figshare.21431547) displays CC BY 4.0. This discrepancy must be resolved against the actual downloaded artifact terms before redistribution; the repository code MIT license is not a license for dataset images. Attribute Arya et al. and the official dataset source; preserve applicable attribution/share-alike notices. This project bundles no RDD2022 images, archives or model weights.

Official source: https://github.com/sekilab/RoadDamageDetector

Dataset archives are too large for normal Git history. Keep data in Colab/Drive or external storage. Keep trained checkpoints out of Git; publish a documented release or model-hosting link only after reviewing license terms, size, provenance and SHA-256. Never store credentials in notebooks or reports.

Screenshot test imagery is generated locally and explicitly labelled synthetic. It is not RDD2022 data or evidence of trained-model performance.
